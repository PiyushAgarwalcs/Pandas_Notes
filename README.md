# Pandas Notes

Jupyter notebook of Pandas notes with worked examples.

## Topics (`Pandas.ipynb`)

- **Series:** creation from lists and dicts, attributes, methods, indexing and slicing, editing, boolean indexing, plotting
- **DataFrame:** creation, attributes and methods, math methods, selecting rows and columns, filtering, adding columns
- **Analysis:** GroupBy, merging, joining and concatenating, MultiIndex DataFrames
- Copies vs views

## Run it

```bash
pip install pandas matplotlib jupyter
jupyter notebook Pandas.ipynb
```
